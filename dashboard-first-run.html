First run

The steward hasn't read your repositories yet. The first tick reads each one, works the queue within its size limits, and fills this page with decisions, PRs ready to merge, staged replies and the plan for the next tick. It takes a few minutes on a large backlog.

Progress shows under the top bar. This page swaps itself for the real one when the tick finishes.

What a tick does

Reads
Open issues, PRs and discussions you've asked it to watch, into a ledger per repository.
Works
Triage replies, PR reviews, delta re-reviews and fix PRs, in priority order and within the tick's size limits.
Stages
PRs it would merge go under Ready for your final look. Everything else it drafted goes under Staged replies.
Escalates
Design direction, breaking changes and close/reject calls go under Decisions needed.
Mode
In draft it posts nothing: every outbound message waits for your click. Change mode, schedule, tick size and watched resources from the top bar.
